# VoiceDirectorV2 v1.7.0

## Summary

Adds an optional wipe-triggered random voice language mode that can temporarily override the normal duty language selection during recovery pulls.

## Highlights

- Added a configuration toggle to enable random language selection after a duty wipe.
- Subscribed to duty wipe and recommence events so the temporary language is applied automatically during retry pulls.
- Kept the temporary wipe language higher priority than the standard duty override and default-language fallback logic.
- Persisted the wipe-randomization preference in plugin configuration.
- Expanded resolver tests to cover temporary override and already-selected-language behavior.

## Notes

- The wipe randomizer is disabled by default and must be enabled in the config window.
- Changing territory clears the temporary wipe language and returns the plugin to its usual duty/default behavior.
